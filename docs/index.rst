jokepy est un mini package Python pour générer des blagues aléatoires en français.

🎯 Fonctionnalités principales
------------------------------

* ✅ Génération de blagues aléatoires
* ✅ Support des catégories (sport, travail, animaux, école)
* ✅ Interface en ligne de commande intuitive
* ✅ API Python simple et claire
* ✅ Type hints complets
* ✅ Tests exhaustifs

🚀 Installation rapide
----------------------

.. code-block:: bash

   pip install jokepy

📖 Utilisation basique
----------------------

.. code-block:: python

   from jokepy import get_random_joke
   
   print(get_random_joke())
   # "Pourquoi les plongeurs plongent-ils toujours en arrière ?"
